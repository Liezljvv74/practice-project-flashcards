# Flashcards

A small study tool. Users create question/answer cards, flip them in review mode, and mark each card as known or unknown.

## Stack

- HTML
- CSS
- JavaScript (plain, no framework, no build step)
- localStorage for saving cards
- GitHub Pages for hosting

## Files

Keep everything in these three files:

- `index.html`
- `style.css`
- `app.js`

## How to run it

Open `index.html` in a browser. There is nothing to install and nothing to build.
